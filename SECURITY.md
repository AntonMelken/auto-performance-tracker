# Security / Sicherheit

## Melden / Reporting

Sicherheitslücken in Auto Performance Tracker oder dieser Website bitte vertraulich per E-Mail an contact@melnychuk-anton.de melden, Betreff „Security“. Bitte keine öffentlichen Issues.

Please report security vulnerabilities in Auto Performance Tracker or this website confidentially by email to contact@melnychuk-anton.de with the subject "Security". Please do not open public issues.

Hilfreich sind / Helpful details: betroffene App-Version, Schritte zum Nachstellen, mögliche Auswirkung / affected app version, steps to reproduce, possible impact.

## Unterstützte Versionen / Supported versions

Korrekturen erscheinen für die aktuelle Version im App Store.

Fixes are released for the current version on the App Store.

## Veröffentlichung / Disclosure

Details werden erst nach einer Korrektur veröffentlicht.

Details are published only after a fix is available.
